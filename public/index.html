    What is this

    A preview for every napplet.

    Napshot watches Nostr relays for napplet manifests (root kind 15129 and named kind 35129) that ship without a screenshot. It renders each one in a sandboxed shell, mirrors the PNG to Blossom servers, and publishes a signed NIP-32 label pointing at the exact napplet event. Shells can show a preview without the author changing anything.

    A screenshot is a preview, not an endorsement or a safety guarantee. Captures show the signed-out initial view; features that need an account or network data may look empty.

    How it works

    1. Watch live relay subscriptions for manifests; author screenshots always win.
    2. Capture the napplet's first frame in a sandboxed Paja shell.
    3. Mirror the PNG to at least two Blossom servers, verified by SHA-256.
    4. Label the exact revision with a kind 1985 event.

    For shell implementers

    {
  "kinds": [1985],
  "authors": [trustedSigner],
  "#e": [manifest.id],
  "#L": ["#screenshot"]
}

    Verify the signature, the e target and the image hash before display; fall back between server mirrors.
